Dottie

Directory-first preference synchronization for Linux and GNOME.

Dottie selects configuration directories, reconciles individual files, and stores encrypted snapshots using an existing Atmosphere account and its PDS.

Status: pre-release scaffold. Capture, snapshot and local-state foundations exist; account linking, encryption, synchronization, restore and the background service are not implemented. Do not use it to back up real data.

This host serves three things:

  • client-metadata.json — the OAuth client metadata whose URL is this project's client_id
  • this page, the human-facing client_uri
  • architecture decisions — what was decided, what forced it, and what was rejected
